# 游戏类小工具（以「下班飙一把」为例）

> 视频是赛车、跑酷、消除这类游戏时的做法。先提醒用户：小红书对「小游戏」怎么审没有先例，上架前问平台；定位成「解压小玩具」，不做关卡、付费、排行榜。画面和玩法只借鉴风格，名字、车、路牌全部原创。

## 先想清楚这三件事
1. **一局多长**：手机上 30 秒到 2 分钟最合适，越往后越快、越密，自然结束。
2. **爽点给奖励**：把视频里最爽的那一下做成加分动作，并配上慢动作、音效、振动、飘字。赛车里是「擦边」：变道后贴着车超过去，慢放 0.2 秒、`+50`、连击翻倍、补氮气。
3. **结束 = 产出物**：翻车后出一张 3:4「成绩单」（截图 + 称号 + 数据 + 编号），这才是能晒的东西。称号按成绩分档，写成用户的梗（「刚出公司就翻了」…「通勤之神」）。

## 伪 3D 赛道（不用 WebGL）
80 年代 OutRun 的分段投影，纯 2D Canvas，老手机也能 60 帧：
- 赛道是一串路段（每段长 200），每段带弯曲度 `curve` 和高度 `y`；按"进弯 / 保持 / 出弯"缓动生成，首尾高度接上，循环使用。
- 每帧从相机所在路段往前画约 170 段：投影 → 地面带 → 护墙 → 路肩 → 路面 → 车道线 → 雾；用 `maxy` 裁掉被坡挡住的段。
- 路边贴图、车流、金币挂在路段上，**从远到近**画，按路段的 `clip` 裁掉被坡挡住的部分。
- 竖屏要**各向同性**缩放（x、y 用同一个系数 K），否则车会被拉成瘦高条。半路宽与相机高度之比约 0.8，主角车放在屏幕 80% 高度处。
- 车道离散（4 条），点左 / 右半屏变道，比滑动和陀螺仪都好上手。陀螺仪变道可以做成可选项。
- 主角车、车流、楼、棕榈树、路牌全部预先画成离屏 canvas，运行时只 `drawImage`。

## 手感清单
- 开局倒计时 3-2-1，前方留一段空路，不会一开局就撞。
- 加速按钮按住生效，外圈显示氮气槽；起飞按钮带冷却遮罩。
- 撞车：屏幕抖动 + 短暂闪白 + 慢动作 + 车翻滚 + 烟尘，1.4 秒后弹成绩单。截图等闪光退掉再截。
- 车流不能四条道同时堵死：生成时检查附近已占用的车道。
- 声音全部 WebAudio 现场合成：引擎（锯齿波 + 低通，频率跟车速）、氮气风噪、金币音阶、擦边「嗖 + 叮」、撞车；配乐是合成波（贝斯八分音符 + 琶音 + 轻鼓 + 侧链抽吸），开车时琶音进来。

## 车库（皮肤）
- 「风格差异大」在游戏里就是**奇葩座驾**：超跑、出租车、共享单车、火箭轮椅、电竞座椅、外卖电驴、老头乐、超市购物车。每台配一句梗。
- 越窄的车碰撞宽度越小，更好钻车缝，玩法上也有区别。
- 第一台免费，其余标 🔒，关注作者一次全部解锁，并直接换上刚才点的那台。
- 涉及敏感梗（比如「轮椅」）时先跟用户确认要不要留。

## 传播
- 「叫搭子」：生成带对方名字和自己成绩的挑战卡，加上指向右上角转发按钮的气泡。
- 发笔记默认标题写成绩：「下班飙了 2.31 公里｜下班闪电侠」。

## 录宣传片
- 场景脚本里注入一个自动驾驶（只在录屏时用）：同道前方有车就换到空车道。
- 需要演示撞车时，主动在玩家正前方放一辆车（给游戏留一个只在录屏用的入口）。
- 镜头顺序：首页 → 车库解锁 → 倒计时 → 变道擦边 → 氮气 → 起飞 → 路牌梗 → 翻车 → 成绩单 → 叫搭子 → 发笔记。
